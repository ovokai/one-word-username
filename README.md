Entry for the make.fun competition [bounty page](https://make.fun/c/u-rusdyxbt-one-word-one-username-one-reward-1a191fae).

The competition asks each entrant to send their own make.fun username —
one word, nothing else. `main.ts` (Node standard library only) validates
that the handle fits the gate (a single word of 1–30 characters) and
writes it to `/output/entry.txt`, falling back to a local `entry.txt`
when `/output` is not writable.

Run it with:

```
node main.ts
```
